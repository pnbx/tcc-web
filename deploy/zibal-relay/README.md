# رله‌ی زیبال روی هاست cPanel (بدون هزینه‌ی اضافه)

درگاه زیبال محدودیت IP دارد، ولی سرور سایت (Vercel) IP ثابت ندارد.
راه‌حل: یک فایل PHP کوچک روی هاست cPanel شما اجرا می‌شود و درخواست‌های زیبال
**از IP ثابت همان هاست** ارسال می‌شوند. زیبال فقط IP هاست را می‌بیند ✓

## قدم ۱ — آپلود فایل

1. وارد cPanel شوید → **File Manager**
2. به پوشه‌ی `public_html` بروید
3. فایل `relay.php` همین پوشه را آپلود کنید

اگر خواستید آدرس تمیزتری داشته باشید، یک زیردامنه (مثل `relay.azuraai.ir`)
به همان پوشه وصل کنید؛ اختیاری است.

## قدم ۲ — IP هاست را در زیبال ثبت کنید

در cPanel، ستون کناری: **Shared IP Address** را بردارید (مثلاً `5.144.130.30`).
سپس در پنل زیبال: درگاه‌ها → ویرایش درگاه → محدودیت IP → همان IP را اضافه کنید.
**این همان کاری است که خطای `invalid IP` را حل می‌کند.**

## قدم ۳ — به سایت معرفی کنید

در Vercel، دو متغیر محیطی را ست کنید (محیط Production و در صورت نیاز Preview):

```
ZIBAL_RELAY_URL    = https://<دامنه یا زیردامنه‌ی هاست>/relay.php
ZIBAL_RELAY_SECRET = <همان رازی که در relay.php گذاشته شد>
```

`ZIBAL_RELAY_SECRET` از قبل در `.env` پروژه سایت هست (رشته‌ی ۴۸ کاراکتری).
همان مقدار را در فایل آپلودشده (`relay.php`) نگه دارید یا از `getenv` بخوانید.

سپس یک redeploy بزنید. تا وقتی `ZIBAL_RELAY_URL` خالی باشد، آداپتور
مستقیم به زیبال وصل می‌شود (و روی Vercel با خطای IP رد می‌شود).

## تست

از استور یک محصول ارزان انتخاب کنید و تا صفحه‌ی پرداخت بروید؛ باید به
`gateway.zibal.ir/start/<trackId>` هدایت شوید. سپس `verify` هم از همان رله رد می‌شود.

## امنیت

- فقط با هدر `x-relay-secret` (مقایسه‌ی زمان-ثابت) پاسخ می‌دهد
- فقط سه endpoint مشخص زیبال مجاز است؛ URL دلخواهی قابل ارسال نیست
- محتوای درخواست دست‌نخورده منتقل می‌شود؛ رله چیزی را تغییر نمی‌دهد
- فقط POST پذیرفته می‌شود

## نکته

هر پرداخت چند کیلوبایت ترافیک است؛ محدودیت ترافیک هاست تأثیری ندارد.
اگر هاست IP عوض کرد، فقط IP جدید را در پنل زیبال به‌روز کنید.
