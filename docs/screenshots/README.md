# Screenshots

Drop PNGs here and reference them from the main README. Suggested set:

| File | What to capture |
|---|---|
| `home.png` | landing page, hero + live status panel |
| `tiers.png` | tier table / a player profile |
| `store.png` | store grid with durations |
| `dashboard.png` | member dashboard |
| `console.png` | staff console / monitoring |

Use a real account on a staging deploy, blur anything private (IPs, player
names you do not have permission to publish), and keep them under ~300 KB each.
